# Hangout brand assets

The Hangout mark is an **"H" monogram knocked out of a speech bubble**, on the
app's blue brand gradient (`#4F8DF8 → #2563EB`, the same
`AppColors.brandGradient` used by buttons and FABs).

## Regenerating the icons

`build_logo.py` is the **single source of truth** for the mark. The geometry is
defined mathematically rather than traced from a bitmap, so every launcher
density is rendered crisp from the same numbers instead of being upscaled.

```bash
pip install Pillow
python3 design/build_logo.py     # writes every icon asset
python3 design/verify_logo.py    # renders design/icon_proof.png
```

`build_logo.py` writes:

| Output | Purpose |
|---|---|
| `mipmap-*/ic_launcher.png` | legacy square launcher icon (5 densities) |
| `mipmap-*/ic_launcher_round.png` | legacy round launcher icon (5 densities) |
| `mipmap-*/ic_launcher_foreground.png` | adaptive-icon foreground (5 densities) |
| `hangout_app/assets/app_icon.png` | 1024² master |
| `hangout_app/assets/app_icon.svg` | true vector master |
| `design/logo_master_1024.png` | store / marketing master |

The adaptive background colour lives in
`android/app/src/main/res/values/colors.xml` (`launcher_background`), and the
notification silhouette in `res/drawable/ic_notification.xml`.

## Keep these in sync

Three places encode the same geometry. If the mark is redrawn, update all of
them together:

1. `design/build_logo.py` — the constants at the top.
2. `hangout_app/lib/widgets/brand_logo.dart` — the in-app `BrandLogo`
   (splash + auth screens). Its fractions mirror the Python ones exactly.
3. `res/drawable/ic_notification.xml` — the status-bar silhouette.

## Adaptive-icon safe zone

Android reserves the outer ~33% of the 108dp adaptive canvas; only the centre
**66%** is guaranteed visible once a launcher applies its mask (circle,
squircle, teardrop…). `build_logo.py` scales the mark so its ink lands just
inside that zone, and `verify_logo.py` renders the result under each mask so
regressions are obvious. The mark's tail hangs below the bubble, so the bubble
is deliberately positioned slightly high to keep the whole glyph optically
centred.

## Concept exploration

`logo_concepts/` holds the six AI-generated concepts that were reviewed before
picking this one, plus `ALL_CONCEPTS.png` comparing them at real launcher
sizes. They are kept for reference only — the shipped icon is generated by
`build_logo.py`, not taken from those PNGs.
